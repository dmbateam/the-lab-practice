# The Lab — Solo Practice

Self-paced single-player version of **The Lab**, the Business & Design Metrics module game from [d.MBA](https://d.mba). Live at:

> **https://dmbateam.github.io/the-lab-practice/**

A SaaS metric is stuck. Run the cheapest experiment that tells you the truth, then build only what the data backs — without wrecking the guardrail.

## What this repo is

A static mirror of the solo build. Source of truth for development is the private `dmbateam/the-lab` repo (which also hosts the multiplayer/workshop version). This repo only exists so GitHub Pages can serve the site for free.

**Don't edit files here directly.** Changes get overwritten by the next sync.

## Sync

Run from the private `the-lab` repo: `./scripts/sync_to_the_lab_practice.sh`.
